# Stock Debian Baseline

No stock Debian ISO, benchmark, or result is present yet.

For a fair comparison:

1. Use the same QEMU machine type and CPU count.
2. Allocate identical RAM.
3. Disable graphics acceleration.
4. Use the same ONNX model and test image.
5. Use 30 or more warm inference iterations.
6. Record ISO size, RAM, package count, boot time, inference latency, and CPU utilization.
7. Preserve raw command output and hashes.

No 40% reduction can be claimed until both ISO sizes are measured.
